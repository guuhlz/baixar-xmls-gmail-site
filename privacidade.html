Política de Privacidade – Baixar XMLs NF-e

Última atualização: 25 de outubro de 2026

1. Quem usa

O aplicativo "Baixar XMLs NF-e" é uma ferramenta interna, usada somente pelo titular da conta Google que o autoriza. Ele não é oferecido ao público.

2. Dados acessados

Com a permissão gmail.readonly (somente leitura), o aplicativo acessa os e-mails da aba "Atualizações" que possuem anexos XML ou ZIP, para identificar e baixar os arquivos XML de Notas Fiscais Eletrônicas. Também são lidos o remetente, o assunto e a data desses e-mails para fins de registro.

3. Como os dados são usados

  • Os arquivos XML são salvos no computador do próprio usuário.
  • Dados da nota (número, emitente, valor, data e motorista) e, opcionalmente, o arquivo XML são enviados por notificação ao Telegram configurado pelo próprio usuário.
  • O aplicativo não envia, altera nem apaga e-mails.

4. Compartilhamento

Os dados não são vendidos, compartilhados com terceiros, usados para publicidade nem para treinar modelos de inteligência artificial. Não há servidor do desenvolvedor: tudo é processado no computador do usuário.

5. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Armazenamento e exclusão

O token de acesso e os arquivos baixados ficam somente no computador do usuário, que pode apagá-los a qualquer momento. O acesso pode ser revogado em myaccount.google.com/permissions.
